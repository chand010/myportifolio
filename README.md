# Abdul Ibrahim — Portfolio

A responsive personal portfolio for **Abdul Ibrahim**, a Cyber Security and Digital Forensics graduate interested in application security, penetration testing and secure software development.

## Website

The site is a lightweight static website built with HTML, CSS and JavaScript. It has no build step or external JavaScript dependencies.

## Sections

- Introduction and professional profile
- About and career focus
- Cybersecurity, development and platform skills
- Selected GitHub projects
- Education and technical direction
- Contact links

## Run locally

Open `index.html` in a browser, or serve the folder with a local static server:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Publish with GitHub Pages

1. Open this repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder, then save.
5. After GitHub Pages finishes deploying, the site will be available at:

   https://chand010.github.io/myportifolio/
